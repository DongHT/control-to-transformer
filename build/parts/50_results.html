四条结论

① 非线性是刚需，不是修辞

同一个直立点线性化模型导出的 LQR，在"已经在直立附近"时无可挑剔（0.25 rad 出发 0.3 s 收进 0.02 rad、进入稳态后几乎不出力）， 但在全局任务上只有 27% 成功率、82% 的回合把小车怼进导轨尽头。 能力边界来自线性化的局部性，而不是参数没调好。

② 两种"局部真理"必须切换

能量整定把"甩起来"化成一个标量 Lyapunov 函数，能证明单调收敛，但永远停不住； 局部稳定器反之。带迟滞的切换器是这两者的"胶水"， 代价是控制量在切换瞬间出现约 10 N 的单步跳变——这是最经典的工程副作用。

③ 滑模买到的是鲁棒性

同样面对 +4 N 持续侧风：Energy+LQR 的稳态倾角 RMS 是 0.014 rad， Energy+SMC 是 0.006 rad（小 2.3 倍），代价是力 RMS 高 8%。 这印证了"鲁棒性不是免费的，它是用带宽换来的"。

④ 数据驱动学到了"连续性"，但没学到"鲁棒性"

Transformer 的摆起略快（2.74 s）、稳态角精度差一点（0.0012 rad）， 但最大单步力跳变只有 5.36 N，约为专家的一半：它把"摆起/稳摆"的硬切换 学成了状态历史上的一个平滑映射，不再有模式边界。 反过来说，它在 +4 N 扰动下掉到 80% 成功率、稳态误差 0.215 rad—— 纯度不够：模仿学习的上限就是专家，而专家本身靠的是显式的鲁棒结构。 第 06 节会看到：把目标函数从"模仿"换成"闭环回报"、再把扰动写进训练分布之后， 这个短板能被补回来，同时摆起时间和力矩都优于专家。

诚实的局限

  • 性能天花板 = 专家。这一节的 Transformer 是模仿学习（BC + DAgger），没有超越 Energy+LQR，只是用另一种形式复现它。第 06 节补上了这部分： 同一个网络改用 PPO 目标函数后，摆起时间 2.22 s、力矩 2.06 N，确实超过了专家。
  • 扰动泛化不足。训练里扰动是 2–5 N 的短时脉冲；测试是 4 N 持续 4 s，属于"更长的腿"。60 组里 80% 的成功率 （换一批样本会在 80%~100% 之间跳动）说明分布外泛化仍然只在插值意义上成立。改进方向：域随机化（扰动分布、质量/摩擦参数随机）+ 在线自适应。
  • 没有可行性/稳定性保证。神经网络策略没有 Lyapunov 证书；导轨约束（撞墙率 13% vs 专家 7%）也没有被显式建模， 只能靠数据里隐含的空间约束。工业落地通常要加安全滤波器（CBF / 可达性分析）兜底。
  • 训练付出的隐性成本：先要有能用的专家（本人调这组传统参数花了整个网格搜索）， 再花 300 s CPU 训练。若专家本身不存在（比如无法建模的对象），这条路就要换成直接从数据学动力学 + 优化控制。
  • 离线指标会骗人：验证 MSE 从 1.45e-3 升到 3.4e-3，闭环成功率却从 0% 升到 100%。 数据驱动控制的验收必须用闭环指标。

Control

更强的传统基线

把能量整定换成"能量 + 相位规划"，或用 NMPC（在浏览器里跑不动，但可作为离线 Oracle）， 看 2.7 s 的摆起时间还能压到多少。

Learning

从模仿走向优化

用专家做初始化，再用可微仿真 / 强化学习（PPO、SAC）在"摆起时间 + 力矩 + 撞墙"的 多目标回报上继续优化，才可能突破专家天花板。

Safety

给网络加一个"保证"

在策略输出后串一个控制屏障函数（CBF-QP）或投影层，把导轨与力矩约束 变成硬约束；或对 attractor 区域做可达集验证。
