06模仿学习之后：RL 能超越"教练"吗？

先澄清一个容易混淆的点：Transformer 是网络结构，模仿学习只是学习目标。 同一个网络，可以拿专家动作做回归（BC/DAgger），也可以拿闭环回报做策略梯度（PPO）， 还可以蒸馏 MPC 或做可微仿真。所以"Transformer 只是模仿学习吗"这个问题， 答案取决于你给它喂什么监督信号。
下面做一次受控实验：同一个网络、同一份 BC+DAgger 初始化，只把目标函数从 "匹配专家动作"换成"最大化闭环回报"，看它能不能打过数据来源。

Objective A

行为克隆 / DAgger

损失 = ‖π(s) − πexpert(s)‖²。学到的是专家的决策函数， 上限就是专家本身，且无处不在地继承专家的保守性。

Objective B

策略梯度（PPO）

损失 = −E[优势·比值]。学到的是在你定义的回报下最优的策略， 可以直接优化"多快、多省力、别撞墙"这些你真正关心的指标。

t_up 2.22 s · 力 2.06 N
Objective C

蒸馏更强的专家

把专家换成 NMPC / 轨迹优化等离线 Oracle，仍然用回归学。 也能"超越"，因为天花板跟着数据源一起抬高了——只是代价是要能实时求解那个 Oracle。

实验设置：只换目标函数

  • 网络：完全相同（2 层因果 Transformer，18,177 参数），初始化 = 上面的 BC+DAgger 权重。
  • 动作分布：网络输出当作高斯策略的均值，σ≈0.55 N 可学习；训练时采样，评估时取均值。
  • 回报：每 20 ms 一步 r = cos θ − 0.15p² − 0.5(u/12)² + 0.5·1{|θ|<0.1} − 4·1{撞墙}。 注意这里没有"摆起时间"这一项，速度是 cos θ 累积出来的自然结果。
  • PPO：48 个并行环境，固定 8 s 回合，γ=0.995，clip 0.2，2 epoch，lr 1.5e-4，150 次迭代（CPU 约 9 分钟）。
  • 第二轮（+DR）：在第一轮基础上加入域随机化——60% 的回合随机带 1.5–5 N、持续 1–3 s 的侧向风， 其余回合无扰动；训练 104 次迭代。
  • 评测：与全文完全相同的 60 组随机初值、12 s 闭环、50 Hz；直接用 int8 量化后的权重（也就是浏览器跑的那份）。

读这张表的三句话
① RL 确实超越了专家：摆起时间 2.84 → 2.22 s（−22%），力矩 RMS 2.42 → 2.06 N（−15%）， 力总变差 107 → 65（−40%）。最后这一项即使不优化速度也不会变好，是"少来回折腾"的直接证据。
② 但它在训练分布外崩了：+4 N 持续侧风下成功率 3%（专家 100%）。 注意它的角度误差其实很小（0.037 rad），失败的原因是小车被风推走 —— 训练环境里根本没有风，所以它没学会任何"位移补偿"。
③ 把分布放进训练就行：加入扰动随机化（DR）后，+4 N 成功率回到 100%、 稳态角度 0.013 rad（与专家 0.014 持平），同时保住了大部分收益 （摆起 2.31 s、力 2.12 N、Δu 3.74 N 仍是四者中最平滑的）。

所以"超越数据来源"的准确条件是什么

能超越的：被优化的指标

当对手（专家）是为"可解释、可证明"设计的，它的增益往往偏保守——能量泵增益要为全工况留余量， 切换阈值要为噪声留余量。PPO 不需要这些余量，它直接在这些具体初值上把 tup 压到极限。 这是结构化设计与数值优化的差距，不是"神经网络比控制理论强"。

不能自动超越的：分布外与安全

RL 只在训练分布内"正确"。专家控制器的鲁棒性是写进结构里的（滑模的 η 项、LQR 的稳定性保证）， 而 RL 的鲁棒性只能写进分布里（域随机化）。也没有 Lyapunov 证书： 这段 RL 策略的撞墙率 15% 依然高于专家的 7%，要压下去就得把约束显式放进奖励或加 CBF 安全层。

一句话总结：RL 能超越的是"你写下来的目标"，超越不了"你没写下来的东西"。 这个项目里，写下来的目标是"快、省力、别撞墙"，它赢了；没写下来的是"4 N 持续侧向风下也要站住"， 它输了——直到我把它写进训练分布。
