07复现方式

本页面是单文件、零依赖的：不请求任何 CDN、字体或图片，模型权重以 int8 内联在 HTML 里， 拷到任何浏览器（含离线环境）即可打开全部交互。

代码结构

transformer/
├── index.html            ← 本页面（自包含）
└── build/
    ├── plant.py           拉格朗日模型 + RK4 仿真
    ├── controllers.py     LQR / 能量整定 / 滑模 / 切换
    ├── sweep.py           摆起参数网格搜索
    ├── dataset.py         专家数据生成（含探索噪声）
    ├── model.py           因果 Transformer 策略
    ├── train.py           BC + DAgger 训练
    ├── rl.py              PPO 微调（含域随机化开关）
    ├── export.py          int8 量化 + 导出 + 校验向量
    ├── export_rl.py       RL 权重导出 + 专家/BC/RL 四方对比
    ├── eval_all.py        四控制器统一评测
    ├── build.py           组装本文档
    └── parts/             HTML 片段

从头复现（约 25 分钟，CPU）

cd build
python3 controllers.py     # 打印 LQR 增益与闭环极点
python3 sweep.py           # 摆起增益网格搜索
python3 train.py           # 数据 + 训练 + DAgger（300 s）
python3 rl.py              # PPO 微调（约 9 min）
                           #   再跑一次 dr=0.6 的域随机化版本（约 7 min）
python3 export_rl.py       # 导出两个 int8 策略 + 四方对比
python3 eval_all.py        # 60 组初值统一评测
python3 build.py           # 生成 ../index.html

依赖：numpy、scipy（仅用于解 CARE）、torch（CPU 版即可）。

数据来源声明：本文档中出现的一切数值都是本项目现场测得的，没有引用外部基准—— ① 第 02、05 节的表格与"能力边界"数字来自 eval_all.py 的 60 组随机初值； ② 第 03 节的训练曲线来自 out/train_log.json； ③ 第 04 节交互实验台的所有曲线、指标、注意力热图都是浏览器实时计算的， 与 Python 侧共用同一组微分方程与同一份 int8 权重。
